# Robust Mean-Variance Portfolio Optimization

## Project Overview
This project investigates traditional and robust portfolio optimization techniques using R. It compares different Mean-Variance Optimization approaches and evaluates their performance under portfolio constraints and uncertainty.

## Objectives
- Implement unconstrained Mean-Variance Optimization.
- Implement constrained Mean-Variance Optimization.
- Implement Robust Mean-Variance Optimization.
- Compare portfolio returns, risk and Sharpe ratios.
- Analyse portfolio weights and efficient frontiers.
- Perform sensitivity analysis.

## Dataset
Daily adjusted stock price data for 10 US companies covering January 2019 to January 2024.

## Methods
1. Unconstrained Mean-Variance Optimization
2. Constrained Mean-Variance Optimization
3. Robust Mean-Variance Optimization
